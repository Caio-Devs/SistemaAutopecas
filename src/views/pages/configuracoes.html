Diretrizes de segurança e privacidade
1. Finalidade dos dados

Os dados deverão ser utilizados para as atividades relacionadas à gestão de clientes, fornecedores, funcionários e operações comerciais.

2. Controle de acesso

O acesso às informações deverá respeitar as permissões atribuídas ao perfil de cada usuário.

3. Segurança das informações

O sistema deverá adotar mecanismos de autenticação, autorização, proteção de credenciais e controle de acesso ao banco de dados.

4. Minimização dos dados

Deverão ser coletadas apenas as informações necessárias às finalidades do sistema.

5. Direitos dos titulares

As solicitações relacionadas aos dados pessoais deverão ser tratadas conforme a legislação aplicável, considerando as obrigações legais de retenção.

6. Backup e recuperação

As cópias de segurança deverão ser protegidas contra acessos indevidos, perdas e alterações não autorizadas.

Estas são diretrizes propostas para o projeto acadêmico. Não representam uma certificação de conformidade com a LGPD.
